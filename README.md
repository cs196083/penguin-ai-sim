# 🐧 펭귄 분류 프로젝트 시뮬레이터

**인공지능 기초 Ⅳ단원 「지속 가능 발전 문제 해결」 181~188쪽** 실습을 브라우저에서
그대로 따라갈 수 있게 만든 수업용 시뮬레이터입니다.

학생은 교과서의 **핵심 코드 17개를 빈칸으로 직접 입력**하고, 맞히면 **실제 계산 결과**가
그 자리에서 나타납니다. 파이썬·코랩 설치 없이 어떤 기기의 브라우저에서도 열립니다.

> 👉 **[시뮬레이터 열기](https://cs196083.github.io/penguin-ai-sim/)**

## 수업에서 이렇게 쓸 수 있습니다

| 상황 | 활용 방법 |
|---|---|
| 코랩 실습 **전** | 전체 흐름을 한 번 돌려 보며 각 단계가 무엇을 하는지 미리 파악 |
| 코랩 실습 **중** | 코드가 막힐 때 힌트·정답 확인, 결과가 안 나올 때 정상 출력과 비교 |
| 코랩 실습 **후** | 「코드 복습 퀴즈」와 「실험실」로 정리 및 심화 |
| 기기가 부족할 때 | 교사 화면으로 투영해 k 값·표준화를 바꿔 가며 함께 관찰 |
| 평가 | 188쪽 성취도 평가, 189쪽 자기 평가 체크리스트 포함 |

## 구성 — 교과서 수행 과정 그대로

| 단계 | 내용 | 교과서 |
|---|---|---|
| 1 · 문제 정의 | 상황 제시, 데이터 속성 안내, 기계학습 유형 확인 문제 | 179~181쪽 |
| 2 · 데이터 수집 | `pd.read_csv()` 로 344행 불러오기 | 182쪽 |
| 3 · 데이터 전처리 | `info` `head` `describe` → 결측치 → 이상치 → 시각화 → 속성 선택 → 데이터 분리 | 182~185쪽 |
| 4 · 알고리즘 선정 | k-NN·로지스틱 회귀 준비 + **k-NN 동작 체험** | 186쪽 |
| 5 · 모델 학습 | `fit()` / `predict()` | 186쪽 |
| 6 · 성능 평가 | 정확도 + 혼동행렬 | 187쪽 |
| 7 · 스스로 해결하기 | `StandardScaler` 표준화 + **실험실** | 188쪽 |
| 8 · 정리 | 전체 코드, 코드 복습 퀴즈, 자기 평가 | 189쪽 |

### 특히 수업에 쓸모 있는 두 화면

- **k-NN 동작 체험** — 테스트 펭귄 한 마리를 고르면 가장 가까운 *k*마리를 선으로 잇고,
  그 *k*마리의 투표 결과와 거리를 표로 보여 줍니다. *k*를 바꾸면 판단이 어떻게 달라지는지
  눈으로 확인할 수 있습니다.
- **실험실(188쪽)** — `n_neighbors`, `test_size`, 표준화 여부를 움직이면 전체 과정이 즉시
  다시 계산됩니다. **k-NN 76.1% → 98.5%** 로 뛰는 장면이 표준화를 가르치는 핵심 순간입니다.

## 결과값에 대하여

브라우저에서 돌아가지만 **대충 흉내 낸 숫자가 아닙니다.** NumPy의 MT19937 난수를 그대로
구현해 `train_test_split(random_state=42)` 가 scikit-learn과 **완전히 같은 분할**을 만들고,
k-NN·로지스틱 회귀·정확도·혼동행렬도 동일한 값을 냅니다.

실제 scikit-learn 1.9.1 과 대조한 결과(테스트 67마리 기준):

| | k-NN 정확도 | 로지스틱 회귀 정확도 |
|---|---|---|
| 표준화 전 | 0.7612 | 0.9851 |
| 표준화 후 | 0.9851 | 1.0000 |

혼동행렬도 셀 단위까지 일치합니다.

> 교과서 187쪽의 인쇄된 수치(k-NN 0.8060)와는 조금 다릅니다. 교과서가 사용한 CSV 파일과
> 행 순서가 달라 20%를 떼어 낼 때 뽑히는 펭귄이 달라지기 때문입니다.
> **표준화 전후로 k-NN이 크게 개선된다**는 학습 내용은 그대로 확인됩니다.

## 직접 실행하기

설치할 것이 없습니다. 저장소를 내려받아 `index.html` 을 열면 됩니다.
(또는 로컬 서버: `python -m http.server 8000` 후 `http://localhost:8000`)

```
index.html          화면 구성과 교과서 설명
css/style.css       스타일 (라이트/다크 모드)
js/data.js          펭귄 344행 원본 데이터
js/ml.js            pandas·scikit-learn 계산 엔진 (MT19937, k-NN, 로지스틱 회귀)
js/charts.js        산점도 행렬·히트맵·혼동행렬·비교 그래프
js/app.js           빈칸 채점, 단계 이동, 실험실
data/penguins_size.csv
```

진행 상황(완료한 코드, 체크 표시)은 **그 브라우저에만** 저장됩니다. 서버로 전송되는
정보는 없습니다. 헤더의 `초기화` 버튼으로 지울 수 있습니다.
